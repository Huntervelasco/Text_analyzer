# Text Analyzer (Python)

This is a simple Python program that analyzes a text input.

## Features

* Counts total words
* Calculates word frequency
* Finds the most repeated word

## How it works

The program:

1. Takes user input
2. Cleans punctuation
3. Splits text into words
4. Counts occurrences using a dictionary

## Example

Input:
Hello hello world

Output:
Total words: 3
hello: 2
world: 1

Most frequent word: hello (2 times)
